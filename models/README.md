# Models

`lbpcascade_frontalface.xml`: OpenCV's LBP frontal-face detector, used by `facecam.py`.
It comes from the OpenCV project (https://github.com/opencv/opencv, `data/lbpcascades/`),
distributed under OpenCV's BSD-style license. A typo in the copy shipped with scikit-image
(`featuhreParams`) is corrected here so OpenCV can load it.
